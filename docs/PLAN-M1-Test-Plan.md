## Affected Pages/Routes
- `/login` — email/password AppAuth (not PAT); CSRF; rate-limit/lockout; session rotation

- `/settings/gitlab` — add/test/replace/delete GitLab connection (`read_api`)
- `/settings/security` — logout; revoke all sessions
- `/settings/projects` — enable/disable
- `/dashboard` — authorization-first data; reference metrics; disclaimer
- `/api/*` — AppAuth session + ProjectAccessService; no PAT/password leakage

## Abstractions under test
- `AppAuthProvider` / local password path
- `GitLabCredentialProvider` / PAT path
- `ProjectAccessService` dual authz (independent of credential implementation)
- Domain must not import NVIDIA or AI providers in M1

## Key Interactions
- Admin invites user → email/password login → opaque session cookie (hashed in DB)
- PAT cannot authenticate ReviewPulse login
- Settings: add allowlisted GitLab URL + PAT → validate → enable project → sync → dashboard
- PAT 401 → credential invalid; **ReviewPulse session remains**; user replaces PAT
- 403/404 on project A → only A membership fail closed; project B still works with same PAT
- Logout / deactivate / revoke-all → sessions dead

## Edge Cases

### 1) Repository / AppAuth / session
- Working branch for implementation docs: `main`
- Non-invited user cannot login
- Password Argon2id hashed; absent from DB plaintext and logs
- Session rotation after login; fixation resisted
- Absolute expiry 12h + idle 2h (configurable)
- Deactivate user revokes all sessions; revoke-all action works
- CSRF/Origin on all state-changing requests
- Rate limit + temporary lockout; fingerprints without password/PAT

### 2) GitLab credential lifecycle
- Scope documented/enforced as `read_api` for M1
- No shared/admin PAT fallback in sync coalesce
- 401 → credential invalid + membership invalidate for user+instance; sync stopped for that credential
- 403/404 → membership deny for that user-project only; PAT remains valid elsewhere
- Replace/delete PAT invalidates membership cache; delete → dashboard fail closed for GitLab data
- Admin cannot view plaintext PAT
- PAT/ciphertext never in API response, logs, audit metadata, telemetry

### 3) Commit sync (≠ MR `updated_after`)
- MR sync may use `updated_after`
- Commit sync uses `since`/`until` + lookback/overlap window; **not** `updated_after`
- Upsert/dedupe by `instance + project + SHA`
- M1 refs locked: **all non-archived branches**
- Tests: timestamp boundary; duplicate SHA across refs counted once; mid-page failure does not advance watermark; retry recovers
- Commits outside week window excluded from weekly frequency metric

### 4) Authorization
- Requires session + allowlist + per-user enable + GitLab membership
- Shared cache ≠ authorization
- Membership TTL default 300s (env-configurable); expired/uncertain/error → fail closed; no stale `allowed=true`
- API authorization-first (authorized IDs first); no frontend-only filter of global cache
- IDOR: project ID, connection ID, search, count (and export if present)
- Login without GitLab connection ≠ project data access
- No Claude Members table/filter

### 5) Security extras
- AES-256-GCM: unique nonce, auth tag, key_version; wrong key fails closed
- SSRF: IPv4/IPv6 private/link-local/metadata, DNS rebinding, redirect validation
- HTTPS required in deploy

### 6) KPI reference (no verdicts)
- Commit frequency: count + reference **3–8/week**; **no** pass/fail
- AI-assisted: `[AI] refactor module`, `[ai] add tests`, `fix: timeout [AI]` count; `AI refactor module` does not; absence of tag ≠ “did not use AI”
- Always `verification_status=self_reported`; never labeled as prompt count; no commit→prompt conversion
- LOC / MR size: `unknown`/`not_configured` if formula unlocked — never coerced to fail
- API/UI have no score, grade, pass/fail, đạt/không đạt
- Rule version change does not rewrite historical snapshots
- Email normalization + verified vs unverified alias labeling

### 7) Explicit non-goals in tests
- No NVIDIA/AIReviewProvider code paths in M1 suite
- No OAuth/SSO/mutation tests required for M1 pass

## Critical Paths

- PAT expire → stay logged in → replace PAT → sync resumes
